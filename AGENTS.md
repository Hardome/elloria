## Команды

Используйте Node.js 26.13.0 и pnpm 12.16.1. Целевая версия PostgreSQL — 18.6.
Команды выполняются из корня репозитория:

- `pnpm install --frozen-lockfile` устанавливает зависимости workspace.
- `pnpm run db:setup`, `pnpm run dev` запускают локальное окружение; подробности — в [README](README.md#локальный-запуск).
- `pnpm run codegen` генерирует API-типы и Zod-схемы из `contracts/openapi.yaml`.
- `pnpm run check` проверяет API и Web; тестам API нужен PostgreSQL с правом создавать БД.
- `pnpm run check:containers` собирает и запускает локальные контейнеры приложения.

Источник контракта — `contracts/openapi.yaml`, его редактируют вручную.
`api/src/generated/` меняйте только генерацией и сохраняйте с изменённым контрактом.
Генерируемого web-клиента в проекте нет. Не добавляйте слои и инструменты без задачи.
Соблюдайте настройки форматирования каждого пакета.

## Проверки и Git

Проверяйте изменённое поведение и существенные ошибки. Используйте API-интеграционные
тесты с реальным PostgreSQL; Web проверяйте линтером, типами, сборкой и подходящими
ручными сценариями. Для изменения только документации достаточно ссылок, команд и
`git diff --check`; запуск БД и сборка не требуются.

Перед коммитом, push или PR прочитайте [Git workflow](.agents/skills/git-workflow/SKILL.md).
Не коммитьте в `main`; сохраняйте существующие изменения, публикуйте только по запросу.

Используйте примеры `.env`, не включайте реальные ключи, заявки и дампы в Git.
Черновики и материалы задач храните в исключённом из Git `docs/tmp/`.
