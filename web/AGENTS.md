# Работа с Web

`web/` содержит Next.js App Router, React и Tailwind CSS.

| Задача | Что читать |
| --- | --- |
| Маршруты, компоненты, формы, состояние и запросы | [Правила Web](../docs/rules/web-guidelines.md) |
| Токены, типографика, UI, адаптивность и доступность | [Оформление](../docs/rules/design-system.md) |
| Ручная проверка интерфейса | [Регресс](../docs/guides/regression.md) |

Соблюдайте FSD и границы слоёв из [правил Web](../docs/rules/web-guidelines.md).
Маршруты Next.js находятся в `app/`, компоненты страниц — в `src/pages/`.
Используйте алиас `@/`, публичные API срезов и имеющиеся UI-компоненты.
Клиентские компоненты выделяйте только для интерактивности и браузерных API.
Новые слои и библиотеки добавляйте только при необходимости для задачи.

Команды проверок — в [Web README](README.md).
Из корня приложения используйте `pnpm --filter @elloria/web run <команда>`.
Команда тестов и остальные проверки описаны в [Web README](README.md#проверки).
