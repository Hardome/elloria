# Работа с API

`api/` содержит Fastify, схему Drizzle, миграции и Vitest-тесты.

| Задача | Что читать |
| --- | --- |
| Маршруты, модули, репозитории, контракт, интеграционные тесты | [Правила API](../docs/rules/api-modules-guidelines.md) |
| Схема PostgreSQL, запросы и миграции | [Правила БД](../docs/rules/database-guidelines.md) |
| Переменные окружения, безопасность и экспорт | [Конфигурация API](../docs/guides/api-configuration.md) |

Рукописные импорты используют `#app/*` и `#test/*` без расширения `.js`.
Форматирование проверяется Biome; следуйте существующему стилю.
Не изменяйте `src/generated/` вручную и не редактируйте применённые миграции.

Команды и требования проверок описаны в [API README](README.md).
Из корня приложения используйте `pnpm --filter @elloria/api run <команда>`.
Тесты создают временную БД; не направляйте их в production-окружение.
